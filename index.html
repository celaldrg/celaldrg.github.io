Featured work

Measuring AI in real codebases

Three tools that answer questions every team using AI agents is asking: how much of the code did AI write, does it last, and do agent pull requests get merged. Each runs on any GitHub repository and prints real numbers.

AI code analyticsRust

aichurn

Does AI-written code get rewritten faster? Replays a repository's git history line by line and measures two-week churn, copy/paste and moved code, split between AI-assisted and human commits. Exact replay, checked against the real files. Single binary, no dependencies.

Source ↗ReleasesIssues
$ aichurn denoland/deno
  churn   7.1%  of new lines rewritten or deleted within 14 days
                 new lines   churn
  AI-assisted       71,833     10%
  Human            581,811    6.7%
▲ AI-assisted lines churned 1.5× as often as human lines
AI code analyticsGo

agentprs

How do AI agents' pull requests fare in your repo? Shows what share of recent PRs Copilot, Claude Code, Codex, Cursor, Devin, Jules and 8 more agents opened, how often those get merged and how fast, next to human PRs. Works on any GitHub repo; GitHub Action, SVG card and badge.

Source ↗ReleasesIssues
$ agentprs n8n-io/n8n
  36% of the last 1,000 PRs were opened by AI agents
                 PRs   merge rate   time to merge
  Claude Code    364          89%           23.9h
  Humans         452          88%           23.2h
= Agent PRs get merged about as often as human PRs
AI code analyticsTypeScript

aiblame

How much of this repo did AI write? git blame for the agent era: the share of the code at HEAD written in commits signed by Claude Code, Cursor, Copilot, Codex, Aider, Devin and 9 more agents. Works on any public GitHub repo, writes an SVG card and badge, and can gate CI. Zero dependencies.

Source ↗ReleasesIssues
$ npx github:celaldrg/aiblame obra/superpowers
  32% of the code at HEAD was written with AI
  87 of 660 commits (13.2%) were AI-assisted
  Claude Code  █████▏  25.5%   9,083 lines
  Cursor       █▍       6.4%   2,289 lines

MCP servers, linters and CLIs

Single-purpose tools that fit into CI, cron and pre-commit. Every one ships with tests, a release and real example output.

MCP server · CLITypeScript

shush

Cuts the noise from command output before it reaches an AI agent. Passing tests, progress bars and install logs go; every error and summary stays, and the full output is one call away. MCP server and CLI. On its benchmark: 20,299 → 6,215 tokens (−69%).

Example output
$ shush go test -v ./...
    calc_test.go:26: Slug("Çay Saati") = "çay-saati", want "cay-saati"
--- FAIL: TestSlugTurkish (0.00s)
FAIL	example.com/calc	0.002s
[shush] exit 1 · 880 → 57 tokens (-94%) · hidden: 65 passing test lines

An MCP server with 17 Türkiye-specific tools for Claude, Cursor, VS Code and other clients: official TCMB exchange rates, live earthquakes, the holiday calendar and business-day math, IBAN/TCKN/VKN validation, provinces, prayer times and weather. No API keys.

CLITypeScript

lockdiff

Readable diffs for lockfiles. Turns a 3,000-line package-lock.json change into what a reviewer needs: upgraded, downgraded, added and removed packages, major bumps first. Ten formats (npm, pnpm, yarn, Cargo, Go, Poetry, uv, Pipenv, Composer, Bundler), Markdown for PR comments, zero dependencies.

Example output

  ↑ upgraded   grep                0.2.13 → 0.3.2   major
  ↑ upgraded   grep-printer        0.1.7 → 0.2.2    major
  ↑ upgraded   aho-corasick        1.1.2 → 1.1.3    patch
  + added      windows_* (8)       0.52.6

csvglance

Know a CSV before you load it: type, missing values, distinct count, range, mean and top values for every column in one streaming pass. Detects delimiters, gzip and decimal commas, flags columns that will break an import. Parallel; about a second per million rows.
