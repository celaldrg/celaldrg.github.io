shush

TypeScript

Cuts the noise from command output before it reaches an AI agent. Passing tests, progress bars and install logs go; every error and summary stays, and the full output is one call away. MCP server and CLI. On its benchmark: 20,299 → 6,215 tokens (−69%).

$ shush go test -v ./...
    calc_test.go:26: Slug("Çay Saati") = "çay-saati", want "cay-saati"
--- FAIL: TestSlugTurkish (0.00s)
FAIL	example.com/calc	0.002s
[shush] exit 1 · 880 → 57 tokens (-94%) · hidden: 65 passing test lines

turkiye-mcp

TypeScript

An MCP server with 17 Türkiye-specific tools for Claude, Cursor, VS Code and other clients: official TCMB exchange rates, live earthquakes, the holiday calendar and business-day math, IBAN/TCKN/VKN validation, provinces, prayer times and weather. No API keys.

// ~/.cursor/mcp.json
{
  "mcpServers": {
    "turkiye": { "command": "npx", "args": ["-y", "github:celaldrg/turkiye-mcp"] }
  }
}

todoage

Rust

How old are your TODOs? Finds TODO, FIXME and HACK comments and uses git blame to show who wrote each one and how long ago, oldest first. JSON output and a CI gate for stale ones. Real output on ripgrep:

$ todoage --limit 3
# columns/lines trimmed to fit
AGE      AUTHOR         LOCATION                        TAG   TEXT
8y 6mo   Andrew Gallant crates/searcher/src/sink.rs:607 TODO  In theory, it should be possible to amortize
8y 2mo   Andrew Gallant tests/regression.rs:179         TODO  (burntsushi) Darwin doesn't like this test
8y 2mo   Andrew Gallant tests/regression.rs:192         TODO  (burntsushi) Figure out how to make this test work

certpeek

Go

Checks TLS certificates for one host or hundreds at once: expiry, hostname, trust chain and TLS version. Table or JSON output and exit codes for cron and CI. One binary, standard library only.

$ certpeek github.com expired.badssl.com wrong.host.badssl.com
# columns/lines trimmed to fit
STATUS    TARGET                 EXPIRES     DAYS   NOTES
CRITICAL  expired.badssl.com     2015-04-12  -4215  expired
OK        github.com             2026-11-29  34
CRITICAL  wrong.host.badssl.com  2026-12-28  63     hostname mismatch

envguard

Python

A linter for .env files: syntax errors, duplicates, keys missing from .env.example, and real credentials committed to example files by mistake. Zero dependencies, with a pre-commit hook and GitHub Actions annotations.
