aichurn

Rust

Does AI-written code get rewritten faster? Replays a repository's git history line by line and measures two-week churn, copy/paste and moved code, split between AI-assisted and human commits. Exact replay, checked against the real files. Single binary, no dependencies.

$ aichurn denoland/deno
  churn   7.1%  of new lines rewritten or deleted within 14 days
                 new lines   churn
  AI-assisted       71,833     10%
  Human            581,811    6.7%
▲ AI-assisted lines churned 1.5× as often as human lines

shush

TypeScript

Cuts the noise from command output before it reaches an AI agent. Passing tests, progress bars and install logs go; every error and summary stays, and the full output is one call away. MCP server and CLI. On its benchmark: 20,299 → 6,215 tokens (−69%).

--- FAIL: TestSlugTurkish (0.00s)
FAIL	example.com/calc	0.002s
[shush] exit 1 · 880 → 57 tokens (-94%) · hidden: 65 passing test lines

lockdiff

TypeScript

Go
