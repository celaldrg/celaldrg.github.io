# celaldrg.github.io

Source of [celaldrg.github.io](https://celaldrg.github.io): a one-page portfolio of my open-source projects.

Plain HTML and CSS in a single file. No framework, no build step, no trackers. Dark
theme, responsive down to small phone screens, and readable with JavaScript turned off.
